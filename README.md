# DNA_Sequence_Analyzer

# Overview
A beginning bioinformatics project written in Python. Using it to help teach myself Python and to incorporate my Biology degrees to contribute to my Ph.D. studies. 

It can do the following functions: 
-Calculate DNA sequence length
-Count A, T, C, and G nucleotides 
-Calculate GC and AT content 
-Calculate the percentages of each nucleotide present

# Skill Demonstrated
-Python
-Strings
-Variables 
-User input 
-Basic bioinformatics 

## Example 

Input: ATCGGATCCA

Output: 

Sequence Length: 10 
A: 3
T: 2 
C: 3
G: 2
GC Content: 50.0 %
AT Content: 50.0 %
Percentage of A: 30.0 %
Percentage of T: 20.0 %
Percentage of G: 20.0 %
Percentage of C: 30.0 %
