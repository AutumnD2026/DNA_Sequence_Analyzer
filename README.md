# DNA_Sequence_Analyzer

# Overview
A beginning bioinformatics project written in Python. Using it to help teach myself Python and to incorporate my Biology degrees to contribute to my Ph.D. studies. 

## Features 
-Validates DNA sequences to ensure only valid nucleotide bases
-Calculates DNA sequences in length 
-Calculates both GC and AT content percentages
-Generates the reverse complement sequence 
-Transcibes DNA sequence to RNA sequence 
-Translates RNA sequence into protein sequence using the genetic code 

## Biological Concept Implemented 

### DNA Sequence Validation 
Checks whether an input sequence contains only valid DNA nucleotides: 
-Adenine (A)
-Tymine (T)
-Cytosine (C)
-Guanine (G)

### GC and AT Content Analysis 
Calculates nucleotide composition: 
-GC content: the percentage of guanine and cytosine bases
-AT content: the percentage of adenin and thymine bases

These measurements are commonly used in genomic analysis and sequence characterization.

### Reverse Complement
Generate the complementary DNA strain in reverse orientation using: 
-A to T
-C to G

### Trranscription
Converts DNA sequences into RNA sequences by replacing Thymine (T) wirh Uracil (U)
